# xsw-scripts
Translating matlab scripts for xsw data generation to python.

## Script function
This script does least-square fitting of theoretical rocking curves and XSW yield curves to data in energy. The calculations are based on dynamical diffraction theory with the possibility of convoluting the sample rocking curve with a Si monochromator rocking curve and a Gaussian function accounting for sample imperfection. Non-dipolar corrections can be also included.
